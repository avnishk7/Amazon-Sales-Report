# Amazon Sales Dashboard | Excel Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing Amazon sales data and transforming it into an interactive **Sales Dashboard using Microsoft Excel** as part of my internship at **Innobyte Services**, which I secured through LinkedIn.
<img width="1411" height="234" alt="image" src="https://github.com/user-attachments/assets/566d9587-f18a-41f7-92c6-7b5dd46c35c7" />


The dashboard provides a visual overview of sales performance, order status, product categories, fulfillment methods, and top-performing cities. It helps identify key business trends and supports data-driven decision-making through interactive filters and visualizations.

## 🎯 Project Objectives

- Analyze overall sales performance and order trends.
- Track key performance indicators (KPIs).
- Compare sales across product categories and cities.
- Analyze order fulfillment methods and order statuses.
- Build an interactive dashboard using Excel.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- PivotTables and PivotCharts
- Slicers and interactive filters
- Excel formulas and data aggregation
- Data visualization and dashboard design

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard displays four key metrics:

- **Total Sales:** 78.6M
- **Total Orders:** 129.0K
- **Total Quantity:** 116.6K
- **Average Order Value (AOV):** 609.3

### 2. Sales by Month

Visualizes monthly sales performance to identify changes in sales volume over time.

### 3. Sales by Category

Compares sales across product categories, helping identify categories contributing significantly to overall revenue.

### 4. Sales by Fulfillment

Analyzes sales distribution between Amazon-fulfilled and merchant-fulfilled orders.

### 5. Top 5 Cities by Sales

Highlights the five leading cities by sales value:
- Bengaluru
- Chennai
- Hyderabad
- Mumbai
- New Delhi

### 6. Order Status Analysis

Displays sales value across different order statuses:
- Shipped
- Unshipped
- On the Way

### 7. Interactive Filters

The dashboard includes slicers for:
- B2B transactions
- Product category
- Sales channel

These filters allow users to explore different segments of the sales data.

## 💡 Key Insights

- Total sales amount to approximately **78.6 million**.
- Shipped orders account for the largest share of sales value among the displayed order statuses.
- Amazon fulfillment contributes approximately 54.3M in sales, compared with 24.3M from merchant fulfillment.
- Bengaluru leads the displayed top-five cities by sales, followed by Hyderabad and Mumbai.
- Category-level analysis helps compare the sales contribution of different products.
